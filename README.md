# Bokrah Retail Website & Landing Page

Official modern landing page and release distribution portal for **Bokrah Retail** desktop application.

## Features
- **Modern, Responsive Design**: Built with high-performance semantic HTML5, modern CSS3 (custom properties, responsive flexbox & grid), and vanilla JavaScript.
- **Direct Installer Download Links**: One-click download buttons for official Windows installer (`.exe`), portable edition (`.zip`), and mobile preview packages.
- **Dynamic Release Discovery**: Client-side integration with GitHub Releases API that automatically retrieves the latest release tag, download asset URL, and file size.
- **Bilingual & RTL Support**: Seamless toggle between English and Arabic with native Right-to-Left (RTL) typography.
- **Interactive Product Showcase**: Realistic desktop POS and inventory mockup with real-time cashier UI preview.
- **System Requirements & FAQ**: Detailed hardware specifications, installation guide, and FAQ accordion.

## Local Development & Preview
To preview the website locally:
```bash
# Using python:
python -m http.server 8080

# Or using Node:
npx serve .
```
Then navigate to `http://localhost:8080`.
